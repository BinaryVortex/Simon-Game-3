# Simon Game (Simon-Game-3)

A simple, classic Simon memory game built with HTML, CSS, and JavaScript.

> Test your memory by repeating increasingly long color/sound sequences generated by the game.


## Screenshot

![Simon Game Screenshot](Screenshot%202024-09-13%20151711.png)


## Demo / How to play

1. Open `index.html` in your browser (double-click the file or serve the folder with a static server).
2. Click the Start button to begin.
3. Watch the sequence of highlighted colored pads and sounds.
4. Repeat the sequence by clicking the pads in the same order.
5. If you match the sequence, the game will add one more step and continue — try to reach the highest score you can!


## Features

- Classic Simon gameplay loop (show sequence → player repeats → sequence grows)
- Distinct colors and sounds for each pad
- Simple, responsive UI that works in desktop and mobile browsers
- Easy-to-read code for beginners learning DOM manipulation and event handling

## Run locally

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Simon-Game-3.git

2. Open the project folder and open `index.html` in your preferred browser.

(Optionally) Run a simple static server, e.g. using Python 3:

   python -m http.server 8000

and open http://localhost:8000 in your browser.
